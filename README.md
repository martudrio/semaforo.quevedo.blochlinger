## Proyecto: Semáforo Automático

### Requerimientos Funcionales
1. El semáforo tiene que prender el LED rojo un rato para simular que los autos frenan.
2. El LED amarillo tiene que prenderse menos tiempo para avisar que está por cambiar.
3. El LED verde se tiene que prender para que los autos puedan avanzar.
4. El ciclo de las luces tiene que repetirse solo, sin que tengamos que tocar nada, usando un bucle.
5. El orden de las luces tiene que ser siempre el mismo: primero rojo, después verde, y último amarillo antes de arrancar de nuevo.

### Requerimientos No Funcionales
1. El código de Arduino tiene que usar nombres de variables que se entiendan bien para los pines y los tiempos.
2. En Wokwi hay que armar el circuito conectando los LEDs con sus respectivas resistencias para que no falle la simulación.
3. El programa tiene que correr bien y sin trabarse usando la función de pausa (`delay`).
4. El README del grupo tiene que estar prolijo y ordenado con formato Markdown para que se lea bien.
5. El código tiene que tener comentarios explicados por nosotros para que se entienda qué hace cada parte.

### Historias de Usuario
1. **Como** conductor, **quiero** ver la luz roja bien clara **para** saber cuándo tengo que frenar.
2. **Como** conductor, **quiero** ver la luz amarilla **para** prepararme para parar o avanzar con precaución.
3. **Como** peatón, **quiero** que el semáforo funcione solo y de forma ordenada **para** poder cruzar la calle seguro.
4. **Como** profe, **quiero** ver el código comentado y prolijo **para** ver que usamos bucles y variables como vimos en clase.
5. **Como** parte del grupo, **quiero** tener el diagrama de flujo en el README **para** entendernos entre nosotros antes de programar en Arduino.
